# Naves y Sistemas

Prototipo jugable construido con React + Vite.

## Inicio rápido

```bash
npm create vite@latest naves-y-sistemas -- --template react-ts
cd naves-y-sistemas
npm install
npm install framer-motion lucide-react
npm install -D @testing-library/jest-dom @testing-library/react @types/node @types/react @types/react-dom autoprefixer postcss tailwindcss tslib typescript vite vitest @vitejs/plugin-react
```

Copia los archivos de este repositorio sobre la carpeta creada y luego ejecuta:

```bash
npm run dev
```

## Scripts

- `npm run dev`: entorno de desarrollo.
- `npm run build`: compilación de producción.
- `npm run preview`: previsualización local.
- `npm run test`: pruebas unitarias con Vitest.
- `npm run lint`: verificación de tipos.
